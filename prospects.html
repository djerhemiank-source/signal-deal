📌 Mon pipeline prospects

💡 C’est quoi le pipeline et comment s’en servir ?

Le pipeline est votre tableau de suivi commercial. Ajoutez un prospect intéressant puis faites-le avancer selon ce qui se passe réellement :

  1. À qualifier : vous devez encore vérifier le besoin et le bon contact.
  2. Contacté : un premier e-mail, appel ou message a été envoyé.
  3. RDV : un échange ou rendez-vous est obtenu.
  4. Proposition : vous avez envoyé un devis ou une offre.
  5. Gagné : le prospect devient client.
  6. Perdu : l’affaire n’aboutit pas.
